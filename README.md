# CodeAlpha Machine Learning Internship

Projects for the **CodeAlpha Machine Learning Internship** (November 2026 batch).

| Task | Project | What it does |
| --- | --- | --- |
| Task 3 | [Handwritten Character Recognition](CodeAlpha_HandwrittenCharacterRecognition/) | A CNN that reads handwritten letters A to Z (EMNIST Letters) |
| Task 4 | [Disease Prediction](CodeAlpha_DiseasePrediction/) | Four models predict malignant vs benign breast tumors (UCI Breast Cancer Wisconsin); best: 96.5% accuracy, 0.996 ROC-AUC |

Each folder has its own README with the dataset, approach, results and run steps, plus a notebook that runs in Google Colab.

Built with Python, scikit-learn, XGBoost and TensorFlow/Keras.
